# Imagen del README

`penamiller-light-dark.png` fue generada con la herramienta integrada de
generación de imágenes. El prompt completo está en
[`penamiller-light-dark.prompt.txt`](penamiller-light-dark.prompt.txt).

Es una ilustración comparativa, no una captura de una aplicación ni una
garantía de valores RGB exactos. El panel claro es conceptual: no se han
creado una paleta clara ni ports claros. La paleta canónica sigue en
`../palette.json`. El preview original de KDE se conserva sin modificaciones.
