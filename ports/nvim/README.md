# Neovim

Penamiller is a standalone Neovim colorscheme. The canonical implementation is
[`colors/penamiller.lua`](../../colors/penamiller.lua) at the repository root,
so this repository can be installed directly as a Neovim plugin.

See the [Neovim installation instructions](../../README.md#neovim).

The previous `penamiller.lua` in this directory only supplied Catppuccin color
overrides. It has been replaced, not wrapped: the native theme requires no
Catppuccin modules, configuration, or installation.
